# 전국 고교 인사이트

직접 그린 한반도 시·도 안내 그림에서 전북 심층 대시보드로 이동하는 초기 화면입니다. 다른 지역은 준비 중입니다. 학교알리미 서버 코드는 향후 연동을 위해 보관합니다. `legacy/jeonbuk.html`은 제공받은 전북 대시보드 원본이며 검토되지 않은 스냅샷이 포함되어 있습니다.

## 실행 및 배포

Node.js 20 이상과 Vercel CLI를 설치한 뒤 `vercel dev`로 실행합니다. Vercel 프로젝트 환경변수에 서버 전용 `SCHOOLINFO_API_KEY`를 설정하세요. 키는 저장소, HTML, 브라우저 코드 또는 `NEXT_PUBLIC_` 변수에 넣지 마세요. `.env.example`은 빈 예시입니다. GitHub에는 코드만 올리고 Vercel에서 GitHub 저장소를 연결하는 구성을 권장합니다. 배포 및 저장소 생성은 아직 수행하지 않았습니다.

서버 함수는 선택한 시·군·구의 학교기본정보(apiType 0)만 조회하며 응답을 최대 1시간 공유 캐시합니다. 각 공시 항목이 매년 또는 별도 주기로 갱신될 수 있으므로 조회 시각이 공시 기준일을 의미하지 않습니다. 사용량 제한 및 악용 방지를 위해 공개 운영 전 인증 또는 외부 rate limiting을 추가해야 합니다.

## 현재 상태 및 한계

- 인증키가 제공되지 않아 실제 API 호출과 응답 필드 매핑을 검증하지 못했습니다. 학교알리미 오류 및 빈 결과는 성공으로 표시하지 않습니다.
- 지역 코드 파일은 제공된 XLSX에서 추출했습니다. 2026년 7월 개편을 반영한 전남광주통합특별시(12) 및 인천 지역이 포함됩니다. 이후 변경 사항은 학교알리미 최신 코드표를 확인하여 갱신해야 하며 자동 갱신되지는 않습니다. 전북 스냅샷은 API 자료와 병합되지 않습니다.
- 지도는 프로젝트 내부 SVG 일러스트이며 실제 경계와 축척을 단순화했습니다. 외부 지도 서비스와 지도 타일을 사용하지 않습니다. 행정구역 개편 시 그림도 수동으로 갱신해야 합니다.
- 전국 심층 지표·비교 기능, API의 다른 공시 항목, 학교별 공시 기준연도, 전체 시군구 자동 수집, API 호출량 제어는 아직 구현되지 않았습니다. 학교기본정보만으로 전북 기존 화면의 모든 항목을 채울 수 없습니다.
- API 및 지도 데이터의 항목별 이용조건을 실제 서비스 목적에 맞게 확인해야 합니다.
